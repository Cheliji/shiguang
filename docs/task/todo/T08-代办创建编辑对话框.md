# T08 代办创建/编辑对话框（基础信息）

- **所属阶段**：二 · UI 实现
- **前置任务**：T07
- **类型**：feat

## 任务目标

实现代办创建/编辑对话框的基础字段：名称、描述、代办流程/完成标准，走 Mock 服务闭环。**重复/日期联动是 T09，延期选项是 T10，目标关联待目标模块（v1.0）——本任务一律不做。**

## 任务内容

1. `ui/dialogs/task_edit_dialog.py`：基于 `MessageBoxBase`
   - 字段：名称（必填，单行）、描述（多行）、代办流程/完成标准（多行）
   - 日期固定为"今天"；重复、延期、目标字段**不出现**（后续任务逐个加）
   - 校验：名称为空时禁用确定按钮并提示
   - 布局为 T09/T10 追加字段预留位置（表单自上而下追加）
2. 创建模式：提交调用 `create_todo`（Mock）→ `InfoBar` 成功提示 → 列表自动刷新（T07 信号）
3. 编辑模式：双击 TaskCard 打开并预填 → 调用 `update_todo`
4. 接线 T07 的"＋ 新建代办"按钮
5. pytest-qt：打开对话框 → 填名称 → 确认 → Mock 数据出现记录、列表刷新
