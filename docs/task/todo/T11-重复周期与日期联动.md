# T11 重复周期与日期选择联动

- **所属阶段**：二 · UI 实现
- **前置任务**：T10
- **类型**：feat

## 任务目标

在对话框加入「重复周期 + 计划日期」并排区，按 UI 设计文档 §4.3.3 实现联动展开。

## 任务内容

1. 对话框追加两列并排区：
   - 重复周期下拉（40px）：不重复 / 每日 / 每周 / 每月
   - 计划日期选择器（默认今天）；重复="每日"时标签变"开始日期"
2. 联动展开（§4.3.3）：
   - 每周 → 下方展开星期多选 Pill（一~日，选中 `--primary` 填充白字）
   - 每月 → 下方展开 1~31 日期网格选择
   - 不重复/每日 → 无展开区
3. 切换重复模式保留已填基础字段不清空
4. 提交字段映射：`repeat` / `date` / `weekday`（多选存列表或取第一个，MVP 约定单选存入，多选留 v1.x——记录在对话框 docstring）/ `month_day`
5. **Mock 简化规则**（Mock docstring 注明）：重复模板在今日列表直接显示一条（卡片带"每日/每周"等重复标签），不做真实实例生成（属 T19）
6. 编辑实例时「重复」区只读展示
7. pytest-qt：四种模式创建，验证 Mock 字段正确
