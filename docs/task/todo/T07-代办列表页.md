# T07 代办列表页（今日视图 + 空状态 + 逾期分组）

- **所属阶段**：二 · UI 实现
- **前置任务**：T06
- **类型**：feat

## 任务目标

代办页展示今日待办列表（逾期置顶分组），支持空状态，接 Mock 服务并响应数据变更信号。**不含创建/归档接线（T08/T11），不含筛选 Tab（T12）。**

## 任务内容

1. `ui/pages/todo_page.py`：
   - 顶部标题"代办" + 右上角"＋ 新建代办"按钮（暂不接逻辑）
   - 逾期分组："逾期未处理 (N)"置顶，渲染逾期 TaskCard
   - 今日分组：渲染今日待办 TaskCard
   - 空状态（两组皆空）：图标 + "今天还没有代办，点右上角创建吧"
2. 数据获取：`get_task_service().list_today()` / `list_overdue()`，渲染 TaskCard
3. 连接服务接口的 `changed` 信号 → 重新拉取并刷新列表
4. 摘除 T06 临时预览页的导航入口
5. pytest-qt 冒烟：Mock 数据下卡片数量正确；清空 Mock 后空状态可见

## 涉及文件

- `src/shiguang/ui/pages/todo_page.py`（修改）
- `src/shiguang/ui/main_window.py`（修改：摘除预览页）
- `tests/test_todo_page.py`（新建）
