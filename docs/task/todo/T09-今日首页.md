# T09 今日首页（TodayPage）

- **所属阶段**：二 · UI 实现
- **前置任务**：T08
- **类型**：feat

## 任务目标

按 UI 设计文档 §4.1 实现今日首页（代办模块的主界面），接 Mock 服务渲染。**两个新建按钮本任务不接逻辑（T10 接线）；归档交互不接（T13 接线）。**

## 任务内容

1. `ui/pages/today_page.py`，结构按 §4.1.1：
   - **顶部功能区**（§4.1.2）：状态表情（按完成率 5 档切换）+ 随机励志文案 + 右侧「新建代办」（Primary）/「写日记」（Secondary，点击弹"模块建设中"提示）
   - **DateBar**：接入 T07 组件；点击日期切换下方列表日期；圆点数据来自 Mock（有代办的日期）
   - **概览卡片区**（§4.1.4）：代办概览卡（大数字 + 进度条，数据来自 `today_summary`）；日记状态卡（占位：固定"未记录"样式，按钮提示"模块建设中"）
   - **今日代办列表**：标题 + 计数 Badge；逾期项红条置顶（§4.1.5）；TaskCard 复用
   - 底部通栏「+ 添加今日代办」大按钮（48px，§4.1.5）
   - 空状态：§6.1"今日无代办"
2. 连接 `changed` 信号 → 刷新列表与概览卡片
3. pytest-qt 冒烟：Mock 数据下各区块渲染、计数正确
