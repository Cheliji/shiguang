# T17 重复规则与实例生成服务

- **所属阶段**：三 · 数据层落地
- **前置任务**：T16
- **类型**：feat

## 任务目标

实现真实库的重复模板实例生成：按 daily / weekly / monthly 规则补齐 `[开始日期, 今日+1]` 缺失实例，幂等。替换掉 Mock 的简化展示规则。

## 任务内容

1. `domain/rules.py`（纯函数，重点测试）：
   - `expected_dates(template, end_date)`：daily→每天；weekly→匹配 weekday；monthly→匹配 month_day（**该月无此日则跳过，如 2 月 30 日**）
2. `services/instance_generator.py`：
   - `generate(today)`：遍历模板 → 期望日期 − 已有实例日期（差集）→ 批量创建实例（拷贝模板字段，`repeat='none'`、`template_id=模板id`、`status='pending'`）
   - 唯一约束冲突视为已存在，跳过（兜底幂等）
3. `task_service.create_todo`：创建模板后立即调用生成一次
4. 单元测试：
   - daily 模板跨 3 天重复 `generate`，实例数正确且不重复
   - weekly 只生成匹配星期几的实例
   - monthly 31 号在 2 月跳过
   - 删除模板不影响已生成实例
5. 手工验证：创建"每日"代办 → 改系统日期到次日 → 重新调用 generate → 出现新实例
