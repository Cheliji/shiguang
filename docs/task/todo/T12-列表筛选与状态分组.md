# T12 列表筛选与状态分组

- **所属阶段**：二 · UI 实现
- **前置任务**：T11
- **类型**：feat

## 任务目标

代办页支持「今日 / 待办 / 逾期 / 已归档」视图切换与历史日期查看。**本任务完成后，代办模块全部 UI 交互闭环（Mock 数据下）。**

## 任务内容

1. 页面顶部加分段切换（`Pivot` 或 `SegmentedWidget`）：今日 / 待办 / 逾期 / 已归档
   - 今日：今日待办 + 逾期置顶分组（现状）
   - 待办：全部 pending（按日期升序分组显示日期）
   - 逾期：全部逾期项
   - 已归档：归档记录列表（调用 `list_archived(date)`），TaskCard 归档态展示评分与总结摘要；点击弹出只读归档详情
2. 已归档视图支持日期选择器查看任意一天
3. `ui/dialogs/archive_detail_dialog.py`：只读详情（名称、归档时间、用时、星级、总结全文）
4. pytest-qt：切换四个视图数据正确、互不串扰
