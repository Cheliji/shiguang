# T20 自动延期服务

- **所属阶段**：三 · 数据层落地
- **前置任务**：T19
- **类型**：feat

## 任务目标

实现真实库的逾期代办自动延期扫描（启动接入属 T22）。

## 任务内容

1. `domain/rules.py` 追加纯函数：`is_overdue(task, today)`、`should_auto_delay(task)`
2. `services/delay_service.py`：
   - `scan(today)`：逾期 auto 项 `date = today`、`delay_count += 1`，批量保存，返回延期数；同日重复 scan 幂等
   - 完成后发射 `changed` 信号
3. 单元测试：auto 顺延且计数递增（连续两天各 +1）；default/never 不变；今日待办不受影响；同日重复幂等
4. 手工验证：昨天日期的 auto 代办 → scan → 今日页红条消失（已是今日）、显示"已延期 N 次"

## 涉及文件

- `src/shiguang/domain/rules.py`（修改）
- `src/shiguang/services/delay_service.py`（新建）
- `tests/test_delay_service.py`（新建）

## 验收标准
