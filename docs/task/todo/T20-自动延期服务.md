# T20 自动延期服务

- **所属阶段**：四 · 数据层落地
- **前置任务**：T19
- **类型**：feat

## 任务目标

实现真实库的逾期代办自动延期扫描（启动接入属 T22）。

## 功能描述与流程

1. 判断规则（纯函数）：计划日期早于今天且仍为待办 = 逾期；逾期且延期策略为"自动延期" = 需要顺延。
2. 扫描流程：找出全部需要顺延的代办 → 计划日期改为今天、延期次数 +1 → 批量保存 → 返回本次顺延数量 → 发射变更信号驱动 UI 刷新。
3. 手工验证：把"自动延期"代办的日期设为昨天 → 执行扫描 → 今日页红条消失（已是今日）、卡片显示"已延期 1 次"。

## 边界情况

- "默认（不延期）"与"不延期"策略的逾期代办保持原日期不动，UI 以逾期样式展示；
- 今天的待办不受影响；
- 同一天重复执行扫描是幂等的（已顺延到今天的代办不再被视为逾期）；
- 连续逾期多天：每天扫描一次，延期次数逐天 +1；
- 已归档记录永不参与扫描。

## 验收标准

- [ ] 单测通过：auto 顺延且计数递增（连续两天各 +1）；default/never 不变；今日待办不受影响；同日重复扫描幂等
- [ ] UI 上延期后的代办展示正确

## 备注

- 延期次数仅记录展示，不做惩罚（产品文档 §6）。
