# T03 Task 与 ArchiveRecord 数据模型

- **所属阶段**：一 · 工程与数据基础
- **前置任务**：T02
- **类型**：feat

## 任务目标

按技术设计文档 §4.2 定义 `tasks`、`archive_records` 两张表的 ORM 模型并生成迁移。**只建模，不写业务逻辑。**

## 任务内容

1. `domain/enums.py`：`TaskKind`、`Period`、`Repeat`、`DelayPolicy`、`TaskStatus` 枚举（str 枚举，值与文档一致）。
2. `models/task.py`：`Task` 模型，字段严格对照技术设计文档 §4.2 tasks 表（含 `template_id` 自引用、`related_task_ids` JSON、`weekday`/`month_day` 可空列）。
3. `models/archive.py`：`ArchiveRecord` 模型，`task_id` 外键 + `relationship`。
4. 约束：`UniqueConstraint(template_id, date)`（注意 template_id 为 NULL 的语义——SQLite 中 NULL 不参与唯一冲突，不重复代办不受影响）。
5. 索引：`(status, date)`。
6. 生成并检查 Alembic 迁移脚本。
7. 单元测试：内存库中创建/查询 Task 与 ArchiveRecord，验证外键与唯一约束生效。
