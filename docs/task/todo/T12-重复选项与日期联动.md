# T12 重复选项与日期选择联动

- **所属阶段**：四 · 代办核心交互
- **前置任务**：T11
- **类型**：feat

## 任务目标

在创建/编辑对话框中加入「重复」选项，并根据选择联动切换日期输入组件（产品文档 5.1 的明确要求）。

## 任务内容

1. 对话框追加「重复」下拉：不重复 / 每日 / 每周 / 每月
2. 日期区联动（同一时间只显示一种）：
   - 不重复 → 日期选择器（默认今天）
   - 每日 → 开始日期选择器（默认今天）
   - 每周 → 星期几选择（周一～周日）
   - 每月 → 每月几号（1–31 数字选择）
3. 提交映射到模型字段（`repeat` / `date` / `weekday` / `month_day`），调用 T05/T06 服务；重复模板创建后立即生成今日实例（服务层已实现，确认调用链通）
4. 编辑已生成的实例时，「重复」字段只读展示模板规则，不可修改（改模板规则属于 v1.x 增强，本任务不做）
5. pytest-qt：四种模式各创建一个，验证数据库字段正确

## 涉及文件

- `src/shiguang/ui/dialogs/task_edit_dialog.py`（修改）
- `tests/test_task_edit_dialog.py`（修改：四种模式用例）

## 验收标准

- [ ] 四种重复模式切换时，日期组件正确联动显示/隐藏
- [ ] 四种模式创建的记录字段正确（weekly 存 weekday、monthly 存 month_day）
- [ ] 创建"每日"模板后，今日列表出现对应实例

## 备注

- 联动切换时保留已填的名称/描述/标准，不被清空。
