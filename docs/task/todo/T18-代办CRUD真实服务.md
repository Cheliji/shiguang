# T18 代办 CRUD 真实服务（替换 Mock）

- **所属阶段**：四 · 数据层落地
- **前置任务**：T17
- **类型**：feat

## 任务目标

提供基于真实数据库的代办增删改查服务并接入服务工厂。**归档（T21）、重复展开（T19）、延期扫描（T20）本任务不做**：归档入口暂抛未实现；重复周期不为"不重复"的创建暂以校验错误拒绝（提示将在后续版本支持）。`USE_MOCK` 默认保持 `true`，应用演示能力不受影响。

## 功能描述与流程

1. 创建代办：名称非空（去空白）、完成标准必填、计划日期合法；创建成功后列表与 DateBar 圆点立即可见。
2. 编辑/删除代办：仅待办状态允许；对已归档记录操作返回明确错误。
3. 列表与概览：今日 / 待办 / 逾期 / 已归档 / 今日概览全部来自真实库。
4. 异常体系：参数校验失败、任务不存在、任务已归档三类错误均继承 ValueError，保持 T05 接口契约不变（契约测试与 UI 现有的 `except ValueError` 继续有效）。
5. T05 契约测试参数化复用：同一套用例同时跑 Mock 与真实实现（真实实现每用例独立内存库、独立服务实例）。
6. 手工回归：临时切换 `USE_MOCK=false`，在真实库下完成创建/编辑/删除不重复代办全流程，重启后数据仍在；验证完切回 `true`。

## 边界情况

- 名称为纯空白 → 拒绝创建；
- 完成标准为空 → 拒绝创建（产品 v0.3 起必填）；
- 已归档记录的编辑/删除 → 拒绝；
- 删除不存在的 id → 明确错误而非静默成功。

## 验收标准

- [ ] T05 契约测试对真实实现全部通过
- [ ] 异常路径单测通过
- [ ] 真实库 CRUD 手工验证通过，重启后数据持久

## 备注

- 分步替换期间 `USE_MOCK` 一键切回，保证应用随时可演示。
- 本任务完成后、T19 之前，真实库下创建重复代办会被拒绝，属预期过渡态（T19 补齐），走查时勿误判为 bug。
