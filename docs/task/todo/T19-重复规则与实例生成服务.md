# T19 重复规则与实例生成服务

- **所属阶段**：三 · 数据层落地
- **前置任务**：T18
- **类型**：feat

## 任务目标

实现真实库的重复模板实例生成：按 daily / weekly / monthly 规则补齐 `[开始日期, 今日+1]` 缺失实例（daily 模板不超过其 `end_date`，如有），幂等。

## 任务内容

1. `domain/rules.py`（纯函数，重点测试）：
   - `expected_dates(template, today)`：daily→每天（**且不超过模板的 `end_date`**，`end_date` 为空的长期模板区间为 `[开始日期, 今日+1]`，有结束日期的模板区间为 `[开始日期, min(end_date, 今日+1)]`）；weekly→匹配 weekday；monthly→匹配 month_day（**该月无此日跳过，如 2 月 30 日**）
2. `services/instance_generator.py`：
   - `generate(today)`：遍历模板 → 期望日期 − 已有实例日期 → 批量创建实例（拷贝模板字段，`repeat='none'`、`template_id=模板id`、`status='pending'`）
   - 唯一约束冲突视为已存在跳过（兜底幂等）
3. `task_service.create_todo`：创建模板后立即生成一次
4. 单元测试：daily 跨 3 天不重复生成；daily 模板设 `end_date` 后超过结束日期不再生成；weekly 只生成匹配星期；monthly 31 号 2 月跳过；删模板不影响实例
5. 手工验证：创建"每日"代办 → 改系统日期到次日 → 调用 generate → 出现新实例

## 涉及文件
