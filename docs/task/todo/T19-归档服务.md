# T19 归档服务（事务，替换 Mock）

- **所属阶段**：三 · 数据层落地
- **前置任务**：T18
- **类型**：feat

## 任务目标

实现真实库的归档服务：单事务更新任务状态 + 写入归档记录，恢复 UI 归档能力（T16 中临时禁用的归档按钮重新启用）。

## 任务内容

1. `services/archive_service.py`（或并入 task_service，按接口组织）：
   - `archive(task_id, ArchiveInput)` 真实实现
   - 校验：任务存在且 `pending`；`score ∈ [1,5]` 整数；`duration >= 0`；总结去空白后非空
   - 单事务：`status → 'archived'` + 插入 `ArchiveRecord`，任一步失败整体回滚
   - 归档重复实例只影响该实例，模板不动
   - 提交后发射 `changed` 信号
2. 恢复 UI 归档流程（移除 T16 的禁用/提示）
3. 单元测试：
   - 正常归档：状态变更 + 记录字段完整（含 archived_at）
   - 非法 score（0、6）、负 duration、空总结 → `ValidationError` 且库无变化
   - 重复归档抛异常
   - 模拟插入异常 → 任务状态回滚为 pending
4. 手工回归：归档 → 已归档视图可见详情 → 重启应用数据仍在

## 涉及文件

- `src/shiguang/services/archive_service.py`（新建）或 `task_service.py`（修改）
- `src/shiguang/ui/pages/todo_page.py`（修改：恢复归档）
- `tests/test_archive_service.py`（新建）
