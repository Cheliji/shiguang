# T11 代办创建/编辑对话框（基础信息）

- **所属阶段**：四 · 代办核心交互
- **前置任务**：T10
- **类型**：feat

## 任务目标

实现代办创建/编辑对话框的基础字段：名称、描述、代办流程/完成标准。**重复/日期联动是 T12，延期选项是 T13，目标关联待目标模块（v1.0）——本任务一律不做。**

## 任务内容

1. `ui/dialogs/task_edit_dialog.py`：基于 `MessageBoxBase`
   - 字段：名称（必填，单行）、描述（多行）、代办流程/完成标准（多行）
   - 隐藏/禁用项：日期暂固定为"今天"；重复、延期、目标字段**不出现**（后续任务逐个加）
   - 校验：名称为空时禁用确定按钮并提示
2. 创建模式：提交调用 `task_service.create_todo(date=today)`；成功 `InfoBar` 提示，列表自动刷新（依赖 T10 信号）
3. 编辑模式：双击 TaskCard 打开，预填字段，提交调用 `update_todo`
4. 接线 T10 的"＋ 新建代办"按钮
5. pytest-qt：打开对话框 → 填名称 → 确认 → 数据库出现记录

## 涉及文件

- `src/shiguang/ui/dialogs/task_edit_dialog.py`（新建）
- `src/shiguang/ui/pages/todo_page.py`（修改：按钮接线、双击编辑）
- `tests/test_task_edit_dialog.py`（新建）

## 验收标准

- [ ] 创建后卡片出现在今日列表
- [ ] 双击卡片可编辑并保存
- [ ] 名称为空无法提交
- [ ] 服务层异常（如编辑已归档任务）以 `InfoBar` 错误提示展示，不崩溃
