# T03 项目骨架与开发环境搭建

- **所属阶段**：二 · UI 实现
- **前置任务**：T02
- **类型**：chore

## 任务目标

搭建可运行的空 PySide6 工程：依赖装好、目录结构就位、空白窗口能启动、测试与 lint 工具可用。**本任务不涉及任何业务界面。**

## 任务内容

1. 创建 `pyproject.toml`：项目元信息、依赖（`PySide6`、`PySide6-Fluent-Widgets`、`SQLAlchemy>=2.0`、`alembic`、`platformdirs`）、dev 依赖（`pytest`、`pytest-qt`、`ruff`）、ruff 配置（行宽 100）。
2. 创建虚拟环境并 `pip install -e .[dev]`。
3. 按技术设计文档 §3.2 创建目录结构（空的 `__init__.py` 即可）：`src/shiguang/{domain,models,db,repositories,services,ui/{pages,dialogs,widgets},resources}` 与 `tests/`。
4. 编写 `main.py`：创建 QApplication，显示一个标题为"拾光"的空白 `QMainWindow`。
5. 编写示例测试 `tests/test_smoke.py`，确认 pytest 可用。
6. 验证 `ruff check .` 与 `ruff format --check .` 通过。

## 涉及文件

- `pyproject.toml`（新建）
- `src/shiguang/main.py`（新建）
- 各空目录 `__init__.py`
- `tests/test_smoke.py`（新建）

## 验收标准

- [ ] `python -m shiguang.main` 能弹出标题为"拾光"的空白窗口
- [ ] `pytest` 运行通过
- [ ] `ruff check .` 无错误
- [ ] 目录结构与技术设计文档一致

## 备注

- 若 qfluentwidgets 与 PySide6 版本冲突，以 qfluentwidgets 要求的版本为准。
- SQLAlchemy/alembic 现在只是装上，阶段三才使用。
