# T23 日期筛选器组件重构（自定义矢量图标下拉）

- **所属阶段**：三 · 补充修复（走查反馈）
- **前置任务**：T14
- **类型**：refactor

## 任务目标

按 UI 设计文档 §4.2.3 / §5.6，把代办列表页「日期筛选器」从原生 `QComboBox` 重构为自定义矢量图标下拉组件：

- 触发器：`calendar` 矢量图标 + 当前筛选文案 + `chevron-down` 矢量图标；
- 下拉面板：白色背景、圆角 12px、阴影 `--shadow-lg`；
- 选项：全部日期 / 今天 / 最近7天 / 最近30天 / 自定义范围（自定义范围依赖独立日历组件，可先占位禁用）。

## 任务内容

1. 新建 `ui/widgets/date_filter.py`（或扩展 `form_fields.py`）：
   - 触发器为自定义按钮/容器，禁止使用 Qt 原生下拉箭头，禁止手绘或用字符模拟图标；
   - 左侧 `calendar.svg`、右侧 `chevron-down.svg` 复用 `ui/icons.py` 的 `colored_icon` / `colored_pixmap`；
   - 下拉面板使用 `QMenu` 或自绘 popup，白色背景、圆角 12px、阴影 lg；
2. 接线 `TodoPage` 四视图，日期筛选与「今日 / 待办 / 逾期 / 已归档」组合结果正确、互不串扰；
3. 移除当前临时 `ChevronComboBox` 方案（本次仅作为原生箭头过渡替代）；
4. pytest-qt 覆盖：四视图 × 日期筛选组合。

## 涉及文件

- `src/shiguang/ui/widgets/date_filter.py`（新建）
- `src/shiguang/ui/pages/todo_page.py`（修改）
- `src/shiguang/ui/widgets/form_fields.py`（可能扩展）
- `tests/test_todo_page.py`（修改）

- [ ] 四视图 × 日期筛选组合数据正确、互不串扰
- [ ] 视觉与 UI 设计文档 §4.2.3 一致（图标、圆角、阴影）
- [ ] pytest-qt 通过，ruff 无告警
