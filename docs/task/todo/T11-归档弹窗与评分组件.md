# T11 归档弹窗与评分组件

- **所属阶段**：二 · UI 实现
- **前置任务**：T10
- **类型**：feat

## 任务目标

实现归档弹窗完整交互（自动带出信息 + 用时 + 评分 + 总结），走 Mock 服务完成归档闭环（卡片从待办消失、进入已归档数据）。

## 任务内容

1. `ui/widgets/rating_widget.py`：5 星评分组件（点击选星、悬停预览、必选）
2. `ui/dialogs/archive_dialog.py`：基于 `MessageBoxBase`
   - 只读带出：名称、描述、代办流程/完成标准
   - 输入：代办用时（分钟，SpinBox，默认 30）、质量评分（RatingWidget）、总结（多行必填）
   - 校验：未评分或总结为空时禁用确定按钮
3. TaskCard 的 `archive_clicked` 信号接线：弹窗 → 确认调用 `archive(task_id, ArchiveInput)` → `InfoBar` 成功提示 → 列表刷新（卡片消失）
4. Mock 服务：`archive` 实现为内存中标记状态 + 保存归档记录（已归档数据供 T12 使用）
5. pytest-qt：弹窗 → 填表 → 确认 → Mock 中状态已归档、记录字段完整、列表已移除
