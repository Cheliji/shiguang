# T10 延期策略选项与逾期展示

- **所属阶段**：二 · UI 实现
- **前置任务**：T09
- **类型**：feat

## 任务目标

对话框加入「延期」选项；完善列表页逾期展示（T06 卡片已支持逾期样式，本任务接线到页面与表单）。

## 任务内容

1. 对话框追加「延期」下拉：默认(不延期) / 不延期 / 自动延期（映射 `default` / `never` / `auto`）
2. Mock 服务支持 `delay_policy` 字段存储与更新
3. 列表页逾期分组确认完善：逾期卡片展示红色竖条、日期红字、"已自动延期 N 次"（delay_count>0 时，Mock 假数据中预置一条演示）
4. 手工验证：Mock 中不同延期策略的卡片展示符合原型

## 涉及文件

- `src/shiguang/ui/dialogs/task_edit_dialog.py`（修改）

- `src/shiguang/ui/pages/todo_page.py`（修改：逾期分组细节）

## 验收标准

- [ ] 三种延期策略可创建并正确保存到 Mock 数据
- [ ] 逾期代办红色标识 + 置顶分组 + 延期次数展示正确
- [ ] 与原型逾期样式一致
