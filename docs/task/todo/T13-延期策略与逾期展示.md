# T13 延期策略选项与逾期展示

- **所属阶段**：四 · 代办核心交互
- **前置任务**：T12
- **类型**：feat

## 任务目标

对话框加入「延期」选项；列表页对逾期代办做醒目展示。

## 任务内容

1. 对话框追加「延期」下拉：默认(不延期) / 不延期 / 自动延期（映射 `default` / `never` / `auto`）
2. TaskCard 逾期样式：`date < today 且 pending` 的卡片——左侧 4px 红色竖条 + 日期红色文案 + 显示延期次数（`delay_count > 0` 时展示"已自动延期 N 次"）
3. 今日视图顶部增加逾期分组：逾期代办置顶显示在今日待办之上，分组标题"逾期未处理 (N)"
4. 手工验证：构造昨天日期的代办 → 重启后 auto 项已顺延到今天（T07 服务在启动序列接入前，可先手动调用 `delay_service.scan` 验证，启动接入属于 T16）

## 涉及文件

- `src/shiguang/ui/widgets/task_card.py`（修改：逾期样式）

## 验收标准

- [ ] 三种延期策略可创建并正确落库
- [ ] 逾期代办有红色视觉标识并置顶分组
- [ ] 自动延期过的代办显示延期次数

## 备注

- `default` 与 `never` 当前行为一致（都不自动延期），保留两个枚举是为后续语义区分（如 never 禁止手动改期）。
