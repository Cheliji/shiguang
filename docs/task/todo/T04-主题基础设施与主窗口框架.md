# T04 主题基础设施与主窗口框架（无边框 + 自绘标题栏）

- **所属阶段**：二 · UI 实现
- **前置任务**：T03
- **类型**：feat

## 任务目标

把 UI 设计文档 §2 的设计令牌落地为 Qt 主题基础设施，并按 §3 实现主窗口框架（**无边框窗口 + 自绘标题栏** + 64px 图标导航 + 页面容器 + 切换动画）。**本任务不含任何业务页面内容。**

## 任务内容

1. **图标准备**（UI 制作要求 #1）：从 Feather Icons / Lucide 下载所需 SVG（home、check-square、book-open、bar-chart-2、settings、plus、calendar、chevron-left/right、x、minimize、maximize 等）存入 `src/shiguang/resources/icons/`，禁止手画
2. `ui/theme.py`：设计令牌常量模块——颜色（§2.1）、字号（§2.2）、间距（§2.3）、圆角（§2.4）、阴影（§2.5）、动效时长（§2.6）。**自定义组件后续只从这里取值，禁止硬编码色值**
3. `resources/styles.qss`：全局样式（滚动条 6px 自定义 §7.5、字体栈 §2.2）
4. **无边框窗口 + 自绘标题栏**（UI 制作要求 #2，规格 §3.3）：
   - `FramelessWindowHint` 无边框；优先复用 qfluentwidgets 的无边框窗口基类处理边缘拉伸/拖拽，不满足则自实现
   - 自绘标题栏 40px：左侧 Logo + "拾光"，右侧自绘最小化/最大化/关闭按钮（SVG 图标，关闭按钮悬停红底）
   - 标题栏拖拽移动、双击切换最大化/还原
5. 导航与页面容器：
   - 按 §3.2.1（64px 固定宽、48px 图标按钮、选中竖线 + `--primary-light` 背景、悬停态、500ms Tooltip）
   - `QStackedWidget` + 250ms 淡入上移切换动画（§7.1）
   - 导航项：今日（默认）/ 代办 / 日记 / 统计（占位"模块建设中"），设置固定底部
   - 窗口 1100×720，最小 960×640，浅色主题
6. 占位页 ×4（`ui/pages/`），今日页留白待 T09
7. 手工验证：对照 prototype/ 比对框架；拖拽、最大化/还原、边缘缩放、关闭均正常
