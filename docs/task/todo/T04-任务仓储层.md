# T04 任务仓储层（TaskRepository / ArchiveRepository）

- **所属阶段**：一 · 工程与数据基础
- **前置任务**：T03
- **类型**：feat

## 任务目标

封装 tasks / archive_records 的全部查询与持久化操作，上层（服务层）不直接写 SQLAlchemy 查询。**本任务无业务规则，只做数据存取。**

## 任务内容

1. `repositories/task_repository.py`：
   - `add(task)` / `get(task_id)` / `update(task)` / `delete(task_id)`
   - `list_pending_todos_by_date(date)`：某日的待办实例 + 不重复代办
   - `list_archived_todos_by_date(date)`
   - `list_overdue(today)`：`status=pending AND date < today`
   - `list_repeat_templates()`：`repeat != 'none' AND status = 'pending'`
   - `list_instance_dates(template_id, date_range)`：查模板已有实例日期（供 T06 差集）
2. `repositories/archive_repository.py`：
   - `add(record)`
   - `count_by_archived_date(date)` / `count_group_by_date(start, end)`（为统计预留，本任务只实现不接线）
3. 单元测试覆盖以上每个方法（内存库）。

## 涉及文件

- `src/shiguang/repositories/task_repository.py`、`archive_repository.py`（新建）
- `tests/test_task_repository.py`、`test_archive_repository.py`（新建）
