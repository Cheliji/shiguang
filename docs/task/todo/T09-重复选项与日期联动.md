# T09 重复选项与日期选择联动

- **所属阶段**：二 · UI 实现
- **前置任务**：T08
- **类型**：feat

## 任务内容

1. 对话框追加「重复」下拉：不重复 / 每日 / 每周 / 每月
2. 日期区联动（同一时间只显示一种，对照原型的联动演示）：
   - 不重复 → 日期选择器（默认今天）
   - 每日 → 开始日期选择器（默认今天）
   - 每周 → 星期几选择（周一～周日）
   - 每月 → 每月几号（1–31 数字选择）
3. 切换重复模式时保留已填的名称/描述/标准，不清空
4. 提交时把 `repeat` / `date` / `weekday` / `month_day` 传给 Mock 服务存储
5. **Mock 简化规则**（写在 Mock 实现 docstring）：每日/每周/每月模板在今日列表直接显示一条（带重复标签，如"每日"），不做真实实例生成——真实逻辑属于 T17
6. 编辑实例时「重复」字段只读展示，不可修改
7. pytest-qt：四种模式各创建一个，验证 Mock 数据字段正确

## 涉及文件

- `src/shiguang/ui/dialogs/task_edit_dialog.py`（修改）
- `src/shiguang/services/mock/mock_task_service.py`（修改：存重复字段 + 简化展示规则）
- `tests/test_task_edit_dialog.py`（修改：四种模式用例）

- [ ] 创建的记录字段正确（weekly 存 weekday、monthly 存 month_day）
- [ ] 每日模板创建后今日列表出现带"每日"标签的卡片
