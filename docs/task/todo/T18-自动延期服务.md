# T18 自动延期服务

- **所属阶段**：三 · 数据层落地
- **前置任务**：T17
- **类型**：feat

## 任务目标

实现真实库的逾期代办自动延期扫描（启动接入属于 T20）。

## 任务内容

1. `domain/rules.py` 追加纯函数：
   - `is_overdue(task, today)`：`pending` 且 `date < today`
   - `should_auto_delay(task)`：`is_overdue` 且 `delay_policy == 'auto'`
2. `services/delay_service.py`：
   - `scan(today)`：取逾期项，auto 项执行 `date = today`、`delay_count += 1`，批量保存，返回延期数量；同日重复 scan 不重复顺延
   - 完成后发射 `changed` 信号
3. 单元测试：
   - auto 逾期项顺延且 `delay_count` 递增（连续两天 scan 各 +1）
   - `default` / `never` 项日期不变
   - 今日待办不受影响；同日重复 scan 幂等
4. 手工验证：构造昨天日期的 auto 代办 → 调用 scan → 卡片移至今日分组并显示延期次数
