# T07 自动延期服务

- **所属阶段**：二 · 业务服务层
- **前置任务**：T06
- **类型**：feat

## 任务目标

实现逾期代办的自动延期扫描：`delay_policy='auto'` 的过期待办自动顺延至当天并累计延期次数；其余保持逾期。**本任务只实现服务与规则，UI 展示属于 T13。**

## 任务内容

1. `domain/rules.py` 追加纯函数：
   - `is_overdue(task, today)`：`pending` 且 `date < today`
   - `should_auto_delay(task)`：`is_overdue` 且 `delay_policy == 'auto'`
2. `services/delay_service.py`：
   - `scan(today)`：取 `list_overdue(today)`，对 auto 项执行 `date = today`、`delay_count += 1`，批量保存；返回延期数量
   - 完成后发射 `task_changed` 信号
3. 单元测试：
   - auto 逾期项顺延且 `delay_count` 递增（连续两天 scan，delay_count = 2）
   - `default` / `never` 项日期不变
   - 今日待办不受影响

## 涉及文件
