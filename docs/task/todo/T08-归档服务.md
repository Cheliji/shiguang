# T08 归档服务（事务 + 事件）

- **所属阶段**：二 · 业务服务层
- **前置任务**：T07
- **类型**：feat

## 任务目标

实现代办归档的完整服务：单事务更新任务状态 + 写入归档记录，含校验，完成后发射 `task_archived` 信号。**UI 归档弹窗属于 T14。**

## 任务内容

1. `services/archive_service.py`：
   - `archive(task_id, duration, score, summary)`
   - 校验：任务存在；`status == 'pending'`；`score ∈ [1, 5]` 整数；`duration >= 0`；summary 去空白后非空（产品文档要求总结必填）
   - 单事务：`task.status → 'archived'` + 插入 `ArchiveRecord`，任一步失败整体回滚
   - 提交后发射 `task_archived(task_id)`
   - 归档的是重复实例时只影响该实例，模板不动
2. 单元测试：
   - 正常归档：状态变更 + 记录字段完整（含 archived_at）
   - 非法 score（0、6）、负数 duration、空 summary → `ValidationError`，且数据库无变化
   - 重复归档同一任务 → `TaskArchivedError` / `ValidationError`
   - 模拟插入记录时异常 → 任务状态回滚为 pending
