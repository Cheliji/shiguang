# T02 原型走查与 UI 设计规格沉淀

- **所属阶段**：一 · 界面原型
- **前置任务**：T01（用户已确认原型）
- **类型**：docs

## 任务目标

从 T01 确认的原型中提炼可执行的设计规格，更新技术设计文档 §6，让阶段二的 PySide6 实现有据可依、不自由发挥。

## 任务内容

1. 提炼**设计令牌**并写入技术设计文档 §6.3：
   - 颜色（主色/文本/边框/逾期红/背景，从原型 CSS 变量中提取具体色值）
   - 字体与字号阶梯、间距阶梯、圆角、阴影
2. 输出**组件 → 实现方式映射表**（写入技术设计文档 §6）：
   - 原型中的每个组件（导航、卡片、下拉、对话框、评分星等）对应 qfluentwidgets 现成组件 / 需自绘或 QSS 定制
3. 标注原型中与 qfluentwidgets 默认样式不一致、需要定制 QSS 的点
4. 更新任务文档中被冻结的 UI 细节（如有）

## 涉及文件

- `docs/技术设计文档.md`（修改 §6）

## 验收标准

- [ ] 设计令牌表完整（每个令牌有具体值，可直接写进 QSS）
- [ ] 每个原型组件都有明确的实现方式结论
- [ ] 用户确认规格无遗漏

## 备注

- 本任务产出后，阶段二 UI 任务以「技术设计文档 §6 + prototype/」为准。
