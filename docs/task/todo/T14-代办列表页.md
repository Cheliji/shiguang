# T14 代办列表页（TodoPage：筛选 + 归档回看）

- **所属阶段**：二 · UI 实现
- **前置任务**：T13
- **类型**：feat

## 任务目标

按 UI 设计文档 §4.2 实现代办列表页：Pill 筛选标签 + 日期筛选 + 归档回看。**本任务完成后，代办模块全部 UI 交互在 Mock 下闭环。**

## 任务内容

1. `ui/pages/todo_page.py`（§4.2.1 布局）：
   - 标题区：「代办」24px SemiBold + 右侧「+ 新建代办」（复用 T10 对话框）
   - 筛选标签栏（§4.2.3）：白色卡片容器；Pill Tabs：今日 / 待办 / 逾期 / 已归档；右侧日期筛选下拉（全部日期 / 今天 / 最近7天 / 最近30天）
   - 列表（§4.2.4）：TaskCard 复用；各视图数据来自对应接口方法
   - 空状态：按 §6.1 分场景文案（暂无代办 / 没有找到匹配的代办→"清除筛选" / 还没有归档记录）
2. 已归档视图：卡片归档态 + 点击弹出只读归档详情弹窗 `archive_detail_dialog.py`（名称、归档时间、用时、星级只读、总结全文）
3. 新建/编辑/归档在本页同样可用（复用 T10/T13）
4. 摘除 T06 临时预览页导航入口（文件保留）
5. pytest-qt：四视图 + 日期筛选组合数据正确
