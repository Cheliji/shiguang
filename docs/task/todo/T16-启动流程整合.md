# T16 启动流程整合（实例生成 + 延期扫描 + 跨天刷新）

- **所属阶段**：五 · 整合
- **前置任务**：T15
- **类型**：feat

## 任务目标

按技术设计文档 §5.1 完成应用启动序列与跨天自动刷新，使重复代办与自动延期在真实使用中无感运行。**本任务是代办模块的收官整合。**

## 任务内容

1. `app.py` 启动序列：
   ```
   QApplication → 定位数据目录 → upgrade_head()
   → InstanceGenerator.generate(today)
   → DelayService.scan(today)
   → 显示 MainWindow
   ```
   启动耗时操作给出简单加载反馈（如 SplashScreen），避免白屏
2. 跨天定时器：`QTimer` 每 60s 检查日期；跨天后重跑 generate + scan 并发射 `task_changed`
3. 窗口激活事件（`QApplication.applicationStateChanged`）也触发一次日期检查（覆盖系统休眠场景）
4. 端到端冒烟脚本/手工 checklist：
   - 创建"每日"模板 → 修改系统日期到次日（或等待） → 重启 → 今日列表出现新实例
   - 创建"自动延期"代办日期为昨天 → 重启 → 顺延到今天且 delay_count=1
5. 回归：pytest 全量通过 + ruff 通过
