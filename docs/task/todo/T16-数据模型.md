# T16 Task 与 ArchiveRecord 数据模型

- **所属阶段**：三 · 数据层落地
- **前置任务**：T15
- **类型**：feat

## 任务目标

按技术设计文档 §4.2 定义 `tasks`、`archive_records` 两张表的 ORM 模型并生成迁移。**只建模，不写业务逻辑。**

## 任务内容

1. `domain/enums.py`：`TaskKind`、`Period`、`Repeat`、`DelayPolicy`、`TaskStatus`（str 枚举）
2. `models/task.py`：字段严格对照技术设计文档 §4.2（含 `template_id` 自引用、`related_task_ids` JSON、`weekday`/`month_day` 可空列）
3. `models/archive.py`：`ArchiveRecord`（`summary` 列**可空**，对齐产品文档 v0.3），外键 + `relationship`
4. 约束：`UniqueConstraint(template_id, date)`；索引 `(status, date)`
5. 生成并检查 Alembic 迁移脚本
6. 单元测试：内存库创建/查询，验证外键与唯一约束

## 涉及文件

- `tests/test_models.py`（新建）
