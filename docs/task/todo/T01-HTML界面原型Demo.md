# T01 HTML 界面原型 Demo

- **所属阶段**：一 · 界面原型
- **前置任务**：无
- **类型**：design

## 任务目标

用纯 HTML/CSS（可加少量 JS 做交互演示）制作代办模块的静态界面原型，覆盖核心页面与交互状态，作为后续 PySide6 UI 实现的**唯一视觉依据**。本任务不写任何真实数据逻辑，全部使用写死的假数据。

## 任务内容

在 `prototype/` 目录下完成原型（单页多区块或多个 html 文件均可，建议单文件多状态切换）：

1. **主界面框架**：左侧导航（今日/代办/日记/统计，仅代办可用，其余置灰占位）+ 右侧内容区
2. **代办列表页**：
   - 今日视图：代办卡片列表（名称、描述摘要、完成标准标识、归档按钮）
   - 空状态：无代办时的引导文案与插画占位
   - 逾期分组：逾期代办置顶、红色标识样式
3. **创建/编辑对话框**：名称、重复下拉、日期选择（演示四种重复模式的联动切换效果）、延期下拉、描述、完成标准
4. **归档弹窗**：自动带出的名称/描述/完成标准（只读样式）、用时输入、5 星评分组件、总结输入
5. **已归档视图**：归档卡片（含星级、总结摘要）

## 设计要求

- 风格：现代简洁，参考 Fluent Design（浅色主题、圆角卡片、克制的配色）
- 布局尺寸参照桌面窗口 1100×720 设计
- 用 CSS 变量管理颜色/间距/圆角，方便 T02 提炼设计令牌

## 涉及文件

- `prototype/index.html`（+ 可能的 css/js 文件）

## 验收标准

- [ ] 上述 5 类界面/状态全部覆盖，浏览器打开可直接查看与简单交互
- [ ] 视觉上达到"现代简洁"预期，由用户亲自评审确认后本任务才算完成

## 备注

- 原型只表达布局、配色、组件形态与关键交互状态，不追求像素完美。
- 用户确认后再进入 T02。
