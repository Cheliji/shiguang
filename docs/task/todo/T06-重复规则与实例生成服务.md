# T06 重复规则与实例生成服务

- **所属阶段**：二 · 业务服务层
- **前置任务**：T05
- **类型**：feat

## 任务目标

实现重复模板的实例生成：按 daily / weekly / monthly 规则，为模板补齐 `[开始日期, 今日+1]` 区间内缺失的实例，保证幂等。

## 任务内容

1. `domain/rules.py`（纯函数，重点测试）：
   - `expected_dates(template, end_date)`：按 repeat 类型计算日期集合
     - `daily`：开始日期起每天
     - `weekly`：匹配 `weekday` 的日期
     - `monthly`：匹配 `month_day` 的日期；**该月无此日（如 2 月 30 日）则跳过该月**
2. `services/instance_generator.py`：
   - `generate(today)`：遍历模板 → 计算期望日期 → 与 `list_instance_dates` 差集 → 批量创建实例（实例字段拷贝模板，`repeat='none'`、`template_id=模板id`、`status='pending'`）
   - 唯一约束冲突视为已存在，跳过（兜底幂等）
3. 将 T05 中创建模板的占位接口替换为真实调用：创建模板后立即生成一次。
4. 单元测试（domain 层全表驱动 + 服务层）：
   - daily 模板跨 3 天重复调用 `generate`，实例数 = 3+1（含前瞻日），不重复
   - weekly 只生成匹配星期几的实例
   - monthly 31 号在 2 月被跳过
   - 删除模板不影响已生成实例
