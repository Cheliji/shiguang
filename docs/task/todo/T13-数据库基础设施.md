# T13 数据库基础设施（引擎 / 会话 / 迁移）

- **所属阶段**：三 · 数据层落地
- **前置任务**：T12
- **类型**：feat

## 任务目标

建立 SQLite 连接、会话管理与 Alembic 迁移骨架。**本任务不定义业务表、不改 UI。**

## 任务内容

1. `config.py`：用 `platformdirs` 解析数据目录（生产 `%APPDATA%/Shiguang`，开发模式用项目 `./data`），暴露 `get_db_path()` 与 `USE_MOCK` 开关
2. `db/session.py`：`create_engine_for(path)`（WAL 模式）、会话工厂与 `session_scope()` 上下文管理器（自动 commit/rollback/close）
3. `models/base.py`：SQLAlchemy 2.x 声明式 `Base`
4. 接入 Alembic：`alembic.ini` 与 `db/migrations/`，连接串从 `config` 读取
5. `db/migration_runner.py`：`upgrade_head()`
6. 单元测试：内存 SQLite 验证 `session_scope` 提交与回滚

## 涉及文件

- `src/shiguang/config.py`（新建）
- `src/shiguang/db/session.py`、`db/migration_runner.py`（新建）
- `src/shiguang/models/base.py`（新建）
- `alembic.ini`、`src/shiguang/db/migrations/`（新建）
- `tests/test_db_session.py`（新建）

## 验收标准

- [ ] `upgrade_head()` 能创建空的 `shiguang.db`
- [ ] 单元测试通过：提交可见、异常回滚
- [ ] 测试全部使用内存库

## 备注

- 不要在模块 import 时创建全局 engine，用函数延迟创建。
