# T04 主窗口与 Fluent 导航框架

- **所属阶段**：二 · UI 实现
- **前置任务**：T03
- **类型**：feat

## 任务目标

对照原型实现主窗口骨架：左侧导航 + 右侧页面容器，含「代办」「日记」「统计」占位页。视觉以 `prototype/` + 技术设计文档 §6 为准。**本任务不做任何业务页面内容。**

## 任务内容

1. `ui/main_window.py`：继承 `FluentWindow`（qfluentwidgets）
   - 导航项：代办（默认选中）、日记、统计（占位页显示"模块建设中"）
   - 窗口标题"拾光"，默认 1100×720，最小 960×640
   - 浅色主题 `setTheme(Theme.LIGHT)`
2. `ui/pages/`：三个占位页（`TodoPage` / `DiaryPage` / `StatsPage`），`TodoPage` 留白待 T07 填充
3. `main.py` 改为启动 `MainWindow`；资源目录放置应用图标并设置
4. 对照原型检查导航样式差异，必要时用 QSS 微调
5. 手工验证：导航切换流畅、窗口尺寸约束生效

## 涉及文件

- `src/shiguang/ui/main_window.py`（新建）
- `src/shiguang/ui/pages/todo_page.py`、`diary_page.py`、`stats_page.py`（新建，占位）
- `src/shiguang/main.py`（修改）
- `src/shiguang/resources/`（图标、QSS）

## 验收标准

- [ ] 启动后呈现与原型一致的导航框架，三页面可切换
- [ ] 窗口尺寸约束生效，浅色主题渲染正常
- [ ] 与原型并排比对，框架布局无明显出入

## 备注

- 第三方组件一律在 `ui/` 内使用，services 层不得 import qfluentwidgets。
