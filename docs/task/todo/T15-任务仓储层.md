# T15 任务仓储层

- **所属阶段**：三 · 数据层落地
- **前置任务**：T14
- **类型**：feat

## 任务目标

封装 tasks / archive_records 的全部查询与持久化操作，服务层不直接写 SQLAlchemy 查询。**本任务无业务规则，只做数据存取。**

## 任务内容

1. `repositories/task_repository.py`：
   - `add / get / update / delete`
   - `list_pending_todos_by_date(date)`、`list_archived_todos_by_date(date)`
   - `list_overdue(today)`、`list_repeat_templates()`
   - `list_instance_dates(template_id, date_range)`（供 T17 差集）
2. `repositories/archive_repository.py`：
   - `add(record)`
   - `count_by_archived_date(date)` / `count_group_by_date(start, end)`（为统计模块预留，本任务只实现不接线）
3. 模型 ↔ DTO 的转换函数（与 T05 的 `TodoItem` 对齐）
4. 单元测试覆盖每个方法（内存库）

## 涉及文件

- `src/shiguang/repositories/task_repository.py`、`archive_repository.py`（新建）
- `tests/test_task_repository.py`、`test_archive_repository.py`（新建）
