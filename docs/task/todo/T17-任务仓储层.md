# T17 任务仓储层

- **所属阶段**：四 · 数据层落地
- **前置任务**：T16
- **类型**：feat

## 任务目标

封装 tasks 表的全部查询与持久化能力。**无业务规则，只做数据存取。**

## 功能描述

1. 基础存取：新增 / 按 id 查询 / 更新 / 删除。
2. 列表查询：
   - 按日期查待办（今日页、代办页"今日"与"待办"视图）；
   - 查已归档（支持按归档日期过滤，也支持不限日期的全量回看）；
   - 查逾期（计划日期早于今天且仍为待办）。
3. 辅助查询：
   - 某日期范围内哪些日期有待办（DateBar 圆点）；
   - 今日概览计数：今日总数 / 已归档数（概览卡片与状态表情）。
4. 统计预留查询：按归档日期分组计数（热力图用，本阶段只实现不接线）。
5. 模型与 DTO 的双向转换与 T05 的 TodoItem 对齐（已归档项附带评分/用时/总结/归档时间）。
6. 表内每条记录都是要展示的代办，所有查询**不需要**"排除模板"之类的特例。

## 边界情况

- 查询返回领域对象/DTO，不向调用方泄露数据库查询对象；
- 空结果返回空列表而非报错；
- 归档查询的"按日期"以归档时间（archived_at）为准，而非计划日期。

## 验收标准

- [ ] 上述每项存取能力都有单测且通过（内存库）
- [ ] 返回值中不出现 ORM 查询对象
