# T17 任务仓储层

- **所属阶段**：三 · 数据层落地
- **前置任务**：T16
- **类型**：feat

## 任务目标

封装 tasks / archive_records 的全部查询与持久化操作。**无业务规则，只做数据存取。**

## 任务内容

1. `repositories/task_repository.py`：
   - `add / get / update / delete`
   - `list_pending_todos_by_date(date)`、`list_archived_todos_by_date(date)`
   - `list_overdue(today)`、`list_repeat_templates()`
   - `list_instance_dates(template_id, date_range)`（供 T19 差集）
   - `list_dates_with_todos(start, end)`（供 DateBar 圆点）
   - `today_summary(date)`：今日总数 / 已归档数（供概览卡片）
2. `repositories/archive_repository.py`：
   - `add(record)`、`count_by_archived_date(date)`、`count_group_by_date(start, end)`（统计模块预留，只实现不接线）
3. 模型 ↔ DTO 转换函数（与 T05 `TodoItem` 对齐，含归档信息）
4. 单元测试覆盖每个方法（内存库）
