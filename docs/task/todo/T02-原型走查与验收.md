# T02 原型走查与验收

- **所属阶段**：一 · 界面原型
- **前置任务**：T01（用户已初步确认原型）
- **类型**：docs

## 任务目标

对照《UI 设计文档》逐组件走查原型，记录并修订差异，冻结阶段二的 UI 实现依据。（设计令牌已由 UI 设计文档 §2 完整定义，本任务不再重复提炼，只做一致性核对。）

## 任务内容

1. 制作走查清单并逐项核对（原型 vs UI 设计文档）：
   - 设计令牌：§2 色彩/字体/间距/圆角/阴影/过渡，抽查 tokens.css 与实际渲染
   - 全局框架：§3 窗口规格、导航栏（64px、选中竖线、Tooltip）
   - 页面：§4.1 今日首页、§4.2 代办列表页
   - 弹窗：§4.3 创建弹窗、§4.4 归档弹窗
   - 组件：§5.1 TaskCard 三种状态变体、§5.3 评分组件
   - 空状态：§6.1 文案与结构
2. 差异处理二选一：改原型对齐文档，或确有更好方案则先改 UI 设计文档（注明版本变更）再对齐原型
3. 走查结论写入 `prototype/REVIEW.md`（每项 ✅/修订记录）
4. 确认技术设计文档 §6 已标注"以 UI 设计文档为唯一依据"

## 涉及文件

- `prototype/REVIEW.md`（新建）
- `prototype/`（可能的修订）
- `docs/UI设计文档.md`（可能的修订，需升版本号）

## 验收标准

- [ ] 走查清单全部项有结论（✅ 或已修订）
- [ ] 用户确认原型可进入开发

## 备注

- 本任务完成后，阶段二 UI 任务以「UI 设计文档 + prototype/」为准。
