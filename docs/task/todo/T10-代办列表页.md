# T10 代办列表页（今日视图 + 空状态）

- **所属阶段**：三 · UI 基础
- **前置任务**：T09
- **类型**：feat

## 任务目标

代办页展示今日待办代办卡片列表，支持空状态提示与数据变更自动刷新。**本任务只读展示：不含创建、归档按钮逻辑（接线在 T11/T14），不含筛选 Tab（T15）。**

## 任务内容

1. `ui/widgets/task_card.py`：`TaskCard` 组件
   - 显示：名称、描述摘要（单行省略）、完成标准图标（有标准时显示，悬停 tooltip 展示全文）
   - 预留右侧操作区（放占位按钮即可）
   - 样式：圆角 8px 卡片，按设计令牌
2. `ui/pages/todo_page.py`：
   - 顶部标题"代办" + 右上角"＋ 新建代办"按钮（点击暂不接线或弹"即将支持"提示）
   - 中部列表：调用 `task_repository.list_pending_todos_by_date(today)` 渲染 TaskCard
   - 空状态：插画/图标 + 文案"今天还没有代办，点右上角创建吧"
3. 连接 `services/signals.py` 的 `task_changed` 信号 → 列表刷新
4. 手工造数验证（可在测试库插入数据后启动查看）

## 涉及文件

- `src/shiguang/ui/widgets/task_card.py`（新建）
- `src/shiguang/ui/pages/todo_page.py`（修改）
- `tests/test_todo_page.py`（新建，pytest-qt 冒烟：有数据时卡片数正确；无数据时空状态可见）

## 验收标准

- [ ] 数据库有今日代办时，页面正确渲染卡片
- [ ] 无代办时显示空状态
- [ ] 手动触发 `task_changed` 信号后列表自动刷新
