# T09 主窗口与 Fluent 导航框架

- **所属阶段**：三 · UI 基础
- **前置任务**：T08
- **类型**：feat

## 任务目标

将空白主窗口升级为 Fluent 风格应用骨架：左侧导航 + 右侧页面容器，含「代办」「日记」「统计」三个占位页。**本任务不做任何业务页面内容。**

## 任务内容

1. `ui/main_window.py`：继承 `FluentWindow`（qfluentwidgets）
   - 导航项：代办（首页，默认选中）、日记、统计（占位页显示"模块建设中"文案）
   - 窗口标题"拾光"，默认 1100×720，最小 960×640
   - 浅色主题 `setTheme(Theme.LIGHT)`
2. `ui/pages/`：三个占位 `QWidget` 子类（`TodoPage` / `DiaryPage` / `StatsPage`），`TodoPage` 留白待 T10 填充
3. `main.py` 改为启动 `MainWindow`；资源目录放置应用图标并在窗口设置
4. 手工验证：导航切换流畅、窗口尺寸约束生效

## 涉及文件

- `src/shiguang/ui/main_window.py`（新建）
- `src/shiguang/ui/pages/todo_page.py`、`diary_page.py`、`stats_page.py`（新建，占位）
- `src/shiguang/main.py`（修改）
- `src/shiguang/resources/`（图标）

## 验收标准

- [ ] 启动后呈现 Fluent 导航窗口，三页面可切换
- [ ] 窗口最小尺寸限制生效
- [ ] 浅色主题渲染正常，无样式错乱

## 备注

- 第三方组件一律在 `ui/` 内使用，services 层不得 import qfluentwidgets。
