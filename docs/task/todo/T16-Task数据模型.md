# T16 Task 数据模型（单表含归档字段）

- **所属阶段**：四 · 数据层落地
- **前置任务**：T15
- **类型**：feat

## 任务目标

按技术设计文档 v0.2 §4.2 建立唯一的业务表 tasks 并生成迁移。**只建模，不写业务逻辑。**

## 功能描述

1. tasks 一张表同时承载"待办"与"已归档"两种状态：
   - 基本信息：名称、描述、完成标准、计划日期、重复规则、系列标识（series_id）、延期策略与延期次数、状态、关联目标、时间戳；
   - 归档字段：用时、评分、总结、归档时间——待办状态下为空，归档时写回原记录。
2. 枚举约束：kind（todo/goal）、period（day/week/month/year）、repeat（none/daily/weekly/monthly）、delay_policy（default/never/auto）、status（pending/archived），取值与现有 DTO 字符串常量完全一致，UI 零改动；kind / period 本阶段固定为 todo / day，**不进入 TodoItem DTO**（v1.0 目标模块再暴露）。
3. 索引：`(status, date)` 与 `(series_id)`。

## 边界情况

- series_id 仅重复展开生成的记录有值，不重复代办为空；
- 归档字段与状态的一致性（已归档必须有归档时间与评分用时）由服务层保证，模型层字段一律可空；
- 表内不再有模板/实例之分，不存在自引用外键与唯一约束。
