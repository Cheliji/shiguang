# T04 主题基础设施与主窗口导航框架

- **所属阶段**：二 · UI 实现
- **前置任务**：T03
- **类型**：feat

## 任务目标

把 UI 设计文档 §2 的设计令牌落地为 Qt 主题基础设施，并按 §3 实现主窗口框架（64px 图标导航 + 页面容器 + 切换动画）。**本任务不含任何业务页面内容。**

## 任务内容

1. `ui/theme.py`（或 `resources/theme.py`）：设计令牌常量模块——颜色（§2.1）、字号（§2.2）、间距（§2.3）、圆角（§2.4）、阴影（§2.5）、动效时长（§2.6）。**所有自定义组件后续只从这里取值，禁止硬编码色值**
2. `resources/styles.qss`：全局样式（滚动条 6px 自定义样式 §7.5、字体栈 §2.2）
3. `ui/main_window.py`：
   - 导航：按 §3.2.1（64px 固定宽、48px 图标按钮、选中竖线 + `--primary-light` 背景、悬停态、500ms Tooltip）。优先用 qfluentwidgets `NavigationInterface`，样式出入大则自绘 QWidget
   - 页面容器：`QStackedWidget` + 250ms 淡入上移切换动画（§7.1）
   - 导航项：今日（默认）/ 代办 / 日记 / 统计（占位页"模块建设中"），设置项固定底部
   - 窗口：1100×720，最小 960×640，浅色主题，应用 Logo + 标题（§3.3）
4. 占位页 ×4（`ui/pages/`），今日页留白待 T09
5. 手工验证：对照 prototype/ 框架页比对导航与切换动画

## 涉及文件

- `src/shiguang/ui/theme.py`、`ui/main_window.py`（新建）
- `src/shiguang/resources/styles.qss`（新建）
- `src/shiguang/ui/pages/today_page.py`、`todo_page.py`、`diary_page.py`、`stats_page.py`（新建，占位）
- `src/shiguang/main.py`（修改）

## 验收标准

- [ ] 导航样式与 §3.2.1 一致（选中/悬停/Tooltip）
- [ ] 页面切换有 250ms 淡入动画
- [ ] 全局滚动条样式生效（先在某占位页造溢出内容验证）

## 备注

- 图标用 FluentIcon 或内置 SVG（线性 24px 风格，§3.2.1）。
