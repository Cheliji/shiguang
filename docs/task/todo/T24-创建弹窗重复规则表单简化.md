# T24 创建弹窗重复规则表单简化（统一开始/结束日期）

- **所属阶段**：三 · 补充修复
- **前置任务**：T23
- **类型**：refactor

## 任务目标

按 UI 设计文档 v1.3 §4.3.3 调整创建/编辑代办弹窗：所有重复周期（每日/每周/每月）统一使用「开始日期 + 结束日期」（均必填），移除每周星期多选与每月 1~31 日期网格，并提供生成条数实时预览。

## 功能描述与流程

1. 重复周期下拉不变（不重复 / 每日 / 每周 / 每月）。
2. 重复="不重复"：右侧显示单个「计划日期」选择器（默认今天），与现状一致。
3. 重复="每日 / 每周 / 每月"：右侧「计划日期」替换为「开始日期 + 结束日期」两个日期选择器：
   - 开始日期必填，默认今天；结束日期必填，默认空（Placeholder"选择结束日期"）。
   - 每周的"周几"由开始日期隐含决定（从开始日期起每 7 天一条）；每月的"几号"由开始日期的日号隐含决定（每月同一日号一条）。界面上不再出现星期多选与 1~31 日期网格。
4. 日期区下方实时预览小字："将生成 N 条代办（首条 YYYY-MM-DD，末条 YYYY-MM-DD）"，任一日期或重复周期的变化立即刷新预览。
5. 校验边界（预览文字变为红色错误提示，同时确认按钮禁用）：
   - 结束日期为空 → "请选择结束日期"
   - 结束日期早于开始日期 → "结束日期不能早于开始日期"
   - 展开条数超过上限 400 条 → "生成条数超过上限 400 条，请缩短日期范围"
6. 创建成功反馈：重复代办提示"已创建，共生成 N 条代办"；不重复代办维持"已创建代办"。
7. Mock 行为：创建重复代办时在内存中按同一展开规则生成多条记录，今日列表、DateBar 圆点等立即可见对应日期的记录；卡片保留重复标签。
8. 编辑模式：编辑重复系列中的单条记录时，「重复周期 / 开始日期 / 结束日期」只读展示，附小字提示"重复代办的修改仅作用于当前这一条"；其余字段可编辑，保存只影响该条。
9. 切换重复模式时保留已填写的名称/描述/完成标准等基础字段不清空。

## 验收标准

- [ ] 每日 2026-10-22 ~ 2026-11-01 → 预览"将生成 11 条"，创建后该区间每天列表各出现一条
- [ ] 每周 2026-10-22 ~ 2026-11-01 → 预览"将生成 2 条"（10-22、10-29）
- [ ] 每月 2026-10-22 ~ 2027-11-01 → 预览"将生成 13 条"（每月 22 日）
- [ ] 结束日期为空 / 早于开始日期 / 超过 400 条时确认按钮禁用且红色提示正确
- [ ] 星期多选与 1~31 网格在界面上不再出现
- [ ] 编辑重复系列单条记录时重复区只读，保存不影响同系列其他记录
- [ ] pytest-qt 冒烟通过
