# T25 重要程度五色标识（UI + 数据模型字段）

- **所属阶段**：三 · 补充修复
- **前置任务**：T24
- **类型**：feat

## 任务目标

代办新增「重要程度」属性：红 > 橙 > 蓝 > 绿 > 灰五色标识（产品文档 v0.6，UI 设计文档 v1.4）。创建弹窗五色单选，列表卡片名称前色点展示，DTO / Mock / 数据模型同步落地该字段。

## 功能描述与流程

1. 创建/编辑弹窗新增「重要程度」行（位于重复周期区与延期策略区之间）：
   - 5 个圆形色点按钮横向排列（红/橙/蓝/绿/灰），单选；
   - 选中态外圈深色描边环，悬停放大反馈，Tooltip 显示档位名（重要/较重要/中等/较低/普通）；
   - 右侧跟随显示当前选中档文字；
   - 默认选中灰档（普通），必有取值，无需校验。
2. TaskCard：名称前渲染 8px 重要程度色点（Tooltip 档位名）；**普通（灰）档不渲染色点**；归档态/逾期态样式不受影响。
3. 数据流：TodoItem DTO 与 create/update 接口增加 priority 字段；Mock 服务透传并支持编辑；预置假数据覆盖多档重要程度。
4. 数据模型：tasks 表新增 `priority` 列（VARCHAR(10)，默认 'gray'）。0002 迁移尚未发布，直接修订该迁移脚本（不新增 0003）；T17 仓储层照常透传该字段。

## 边界情况

- 不选时默认"普通（灰）"，任何代办都有合法档位；
- 重复代办展开生成的同批记录共享同一重要程度；编辑系列单条记录时可修改，仅作用于当前这一条；
- 编辑弹窗打开时正确回显既有档位；
- 灰档卡片无色点（普通=默认，不产生视觉噪音）。

## 验收标准

- [ ] 弹窗五色单选：默认灰档、切换后文字跟随、选中环样式正确
- [ ] 卡片色点：红/橙/蓝/绿档显示色点，灰档不显示
- [ ] 契约测试：创建默认 gray、指定档位持久、编辑可改
- [ ] 模型/迁移：tasks 表含 priority 列且默认 gray；升级后结构与设计一致
- [ ] pytest 全过 + ruff 通过
