# T14 归档弹窗

- **所属阶段**：四 · 代办核心交互
- **前置任务**：T13
- **类型**：feat

## 任务目标

实现代办完成时的归档弹窗，完整落地产品文档的"归档留痕"交互（自动带出信息 + 用时 + 评分 + 总结）。

## 任务内容

1. `ui/widgets/rating_widget.py`：5 星评分组件（点击选星，必选）
2. `ui/dialogs/archive_dialog.py`：基于 `MessageBoxBase`
   - 只读带出：名称、描述、代办流程/完成标准（对照标准自检，产品文档核心交互）
   - 输入：代办用时（分钟，SpinBox，默认 30）、质量评分（RatingWidget）、总结（多行必填）
   - 校验：未评分或总结为空时禁用确定按钮
3. TaskCard 操作区"归档"按钮接线：弹窗 → 确认调用 `archive_service.archive` → 成功 `InfoBar` 提示，卡片从待办列表移除
4. 服务层异常（如重复归档）以 `InfoBar` 错误提示
5. pytest-qt：归档流程端到端（弹窗 → 填表 → 确认 → 数据库状态与记录正确 → 列表移除）

## 涉及文件

- `src/shiguang/ui/widgets/rating_widget.py`（新建）
- `src/shiguang/ui/dialogs/archive_dialog.py`（新建）
- `src/shiguang/ui/widgets/task_card.py`（修改：归档按钮接线）
- `tests/test_archive_dialog.py`（新建）

## 验收标准

- [ ] 弹窗正确带出名称/描述/完成标准且只读
- [ ] 评分或总结缺失时无法确认
- [ ] 归档成功后列表移除该卡片，`archive_records` 记录完整

## 备注

- 归档弹窗是产品体验核心，注意文案温度（如标题"完成归档 · 给自己打个分吧"）。
