# T15 列表筛选与状态分组

- **所属阶段**：四 · 代办核心交互
- **前置任务**：T14
- **类型**：feat

## 任务目标

代办页支持「今日 / 待办 / 逾期 / 已归档」视图切换与历史日期查看，让留痕数据可看可回溯。

## 任务内容

1. 页面顶部加分段切换（`Pivot` 或 `SegmentedWidget`）：今日 / 待办 / 逾期 / 已归档
   - 今日：今日待办 + 逾期置顶分组（现状）
   - 待办：全部 pending（按日期升序分组显示日期）
   - 逾期：全部逾期项
   - 已归档：归档记录列表，卡片显示归档时间、评分（星级只读）、总结摘要；点击可查看归档详情弹窗（只读）
2. 已归档视图支持日期选择器查看任意一天
3. 复用 TaskCard：已归档模式置灰 + 隐藏操作按钮 + 显示评分
4. pytest-qt：切换四个视图数据正确
