# T21 归档服务（单行更新，替换 Mock）

- **所属阶段**：四 · 数据层落地
- **前置任务**：T18
- **类型**：feat

## 任务目标

实现真实库归档：归档 = 在原任务记录上写入用时/评分/总结/归档时间并翻转状态，**单行更新，无跨表事务**。UI 无需改动（归档入口从未禁用）。

## 功能描述与流程

1. 归档流程：用户在归档弹窗确认 → 校验 → 更新该条记录（状态 → 已归档，写入用时/评分/总结/归档时间）→ 发射变更信号，列表自动刷新（T05 已接线）。
2. 校验规则：任务存在且为待办状态；评分为 1–5 的整数；用时 > 0；总结可为空，非空时去空白且不超过 500 字。
3. 手工回归：归档 → 代办页"已归档"视图可见详情（评分/用时/总结）→ 重启后数据仍在。

## 边界情况

- 重复归档同一条记录 → 拒绝；
- 评分或用时非法 → 拒绝且数据不发生任何变化；
- 总结留空可正常归档；
- 归档重复系列中的一条，只影响该条，同系列其余记录不受影响。

## 验收标准

- [ ] 单测全部通过：正常归档字段完整（含归档时间）；非法评分（0、6）、用时 ≤ 0 被拒绝且库无变化；总结为空可归档；重复归档报错
- [ ] 真实库归档全流程手工验证通过

## 备注

- 归档不可逆（MVP），不提供撤销归档。
