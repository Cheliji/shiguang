# T21 归档服务（事务，替换 Mock）

- **所属阶段**：三 · 数据层落地
- **前置任务**：T20
- **类型**：feat

## 任务目标

实现真实库归档服务：单事务更新状态 + 写归档记录，恢复 UI 归档能力（T18 临时禁用处解禁）。

## 任务内容

1. `archive(task_id, ArchiveInput)` 真实实现：
   - 校验：任务存在且 `pending`；`score ∈ [1,5]` 整数；`duration > 0`；**总结可空**（v0.3），非空时去空白、限 500 字
   - 单事务：`status → 'archived'` + 插入 `ArchiveRecord`，任一步失败整体回滚
   - 归档重复实例只影响该实例
   - 提交后发射 `changed` 信号
2. 恢复 UI 归档入口（Checkbox 点击 → 归档弹窗 → 真实服务）
3. 单元测试：正常归档字段完整（含 archived_at）；非法 score（0、6）、duration<=0 → `ValidationError` 且库无变化；总结为空**可正常归档**；重复归档抛异常；插入异常时任务状态回滚
4. 手工回归：归档 → 代办页已归档视图可见详情 → 重启数据仍在
