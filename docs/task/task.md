# 拾光 · 任务总览

> 本文档描述总体任务进度与任务执行规则。各任务的详细内容见同目录下按模块划分的任务文档。

## 任务执行规则（重要）

1. **严格顺序执行**：任务按编号从小到大进行，前置任务未完成不得开始后续任务；任务跳度已按"最小可验证功能"拆分，禁止自行合并任务。
2. **最小粒度**：每个任务只完成文档中描述的内容，**不实现后续任务的功能**（如 T11 只做基础字段表单，不做日期联动）。
3. **一任务一提交**：每个任务完成并满足验收标准后，立即创建一个 git commit（遵循 AGENT.md），提交信息格式：`类型(Txx): 描述`，如 `feat(T05): 代办 CRUD 服务`。
4. **验收驱动**：任务完成的标准 = 该任务文档「验收标准」一节全部通过（含单元测试）。通过后回本文档更新状态为 ✅。
5. **文档同步**：实现过程中若与技术设计文档产生偏差，先更新设计文档再写代码。
6. **测试要求**：服务层/领域层任务必须附带 pytest 单元测试；UI 任务至少手工走通验收标准。
