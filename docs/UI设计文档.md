## 1. 设计概述

### 1.1 设计理念

**「克制、呼吸、留痕」**

- **克制**：不堆砌功能入口，每个页面只呈现当前场景最核心的信息。颜色极度收敛，以灰白为底，主色仅用于强调当前状态与关键行动点。
- **呼吸**：大量留白（White Space），卡片间距宽松，信息层级通过间距而非分割线来区分。Kite 的 8px 间距体系被延续并扩展。
- **留痕**：拾光的核心差异——"完成标准"与"归档复盘"必须在 UI 上被"看见"而非隐藏。代办卡片上永远展示完成标准摘要，归档弹窗被赋予仪式感。

### 1.2 Kite 美学要素在拾光中的映射

| Kite 特征                   | 拾光应用方式                                             |
| --------------------------- | -------------------------------------------------------- |
| 顶部横向日期栏（周一~周日） | 「今日」与「代办」页面顶部保留周视图日期栏，点击切换日期 |
| 圆角卡片 + 柔和阴影         | 代办卡片（TaskCard）圆角 12px，阴影随悬停加深            |
| 复选框极简勾选              | 代办完成使用圆形 Checkbox，点击即归档（弹出归档窗）      |
| 底部/顶部大号操作按钮       | 新建代办使用通栏大按钮，降低行动门槛                     |
| 表情/状态指示器             | 今日首页顶部显示今日状态表情（根据完成率变化）           |
| 浅色灰白背景                | 全局背景 #F3F4F6，卡片纯白，无彩色渐变                   |
| 紧凑字体 + 清晰层级         | 标题 20-24px，正文 14px，辅助 12-13px                    |

## 2. 设计系统（Design Tokens）

### 2.1 色彩体系

拾光采用 **单主色（Teal）+ 中性灰阶** 的配色策略，符合 Fluent Design 浅色主题规范，同时继承 Kite 的低饱和度干净感。

| `--bg-primary`       | `#F3F4F6` | 全局页面背景（Gray-50）             |

| `--bg-tertiary`      | `#D1D5DB` | 禁用状态、占位符（Gray-300）        |

### 3.1 窗口规格

| 属性     | 值                                |
| -------- | --------------------------------- |
| 默认尺寸 | 1100px × 720px                    |
| 最小尺寸 | 960px × 640px                     |
| 背景色   | `--bg-primary` (#F3F4F6)          |
| 主题     | 浅色优先，`setTheme(Theme.LIGHT)` |

### 3.2 布局结构（Grid）

```
┌─────────────────────────────────────────────────────────────┐
│ TitleBar (系统标题栏，可嵌入自定义控件)                         │  32px
├────────┬────────────────────────────────────────────────────┤
│        │                                                    │
│  Nav   │              Page Content Area                     │
│Sidebar │         (StackedWidget / 页面容器)                  │
│ 64px   │                                                    │
│        │                                                    │
│        │                                                    │
│        │                                                    │
```

#### 3.2.1 左侧导航栏（NavSidebar）

- **宽度**：64px（固定，不展开）
- **背景**：`--surface` (#FFFFFF) + 右侧 1px 边框 `--bg-secondary`
- **布局**：垂直居中排列图标按钮，每个按钮 48px × 48px
- **间距**：图标之间 4px 间距
- **选中态**：
  - 左侧 3px 宽 `--primary` 色竖线指示器（圆角 0 2px 2px 0）
  - 图标颜色变为 `--primary`
  - 背景变为 `--primary-light`
  - 圆角 `--radius-md` (8px)
- **悬停态**：背景 `--bg-primary`，圆角 8px，150ms 过渡
- **Tooltip**：鼠标悬停 500ms 后显示页面名称（如"今日""代办"），白色背景小浮层

**导航项（MVP，从上到下顺序）**：

| 顺序 | 图标            | 页面 | 说明                 |
| ---- | --------------- | ---- | -------------------- |
| 1    | 🏠 / Home        | 今日 | 默认选中，首页       |
| 2    | ☑️ / CheckSquare | 代办 | 全部代办管理         |
| 3    | 📝 / BookOpen    | 日记 | 每日复盘             |
| 4    | 📊 / BarChart2   | 统计 | 数据可视化           |
| 5    | ⚙️ / Settings    | 设置 | 底部固定，分割线分隔 |

> 图标风格：线性图标（Stroke 2px），24×24px 视口，无填充。

#### 3.2.2 页面内容区（Page Content Area）

- **背景**：`--bg-primary` (#F3F4F6)
- **内边距**：`--space-xl` (24px) 四边
- **内部布局**：各页面自行管理，通常为纵向 Flex 布局
- **滚动**：页面内容超出时允许纵向滚动，滚动条样式需自定义（宽 6px，轨道透明，滑块 `--bg-tertiary`，圆角 3px）

### 3.3 顶部标题栏（TitleBar）

拾光**禁止使用 PySide6 原生标题栏**（最小化/最大化/关闭系统栏），窗口采用无边框方案（`FramelessWindowHint`），标题栏完全自绘：

- **高度**：40px，背景 `--surface`，底部 1px 边框 `--bg-secondary`
- **左侧**：应用 Logo（16px 风筝/沙漏图标）+ "拾光" 文字（14px, medium）
- **右侧**：自绘窗口控制按钮（最小化 / 最大化/还原 / 关闭），各 40px×40px，使用矢量图标；悬停时最小化/最大化为 `--bg-primary` 背景，关闭按钮为 `--danger` 红底白图标
- **交互**：标题栏区域支持拖拽移动窗口、双击切换最大化/还原；无边框窗口需自行实现边缘拉伸缩放（或使用 qfluentwidgets 的无边框窗口基类）
- **实现参考**：qfluentwidgets 提供无边框窗口支持，可直接复用其标题栏方案并按上述样式定制

**用途**：用户打开应用的第一屏，聚合今日所有待办、快速创建入口、日记快捷通道。

#### 4.1.2 顶部功能区（Top Action Bar）

- **高度**：56px
- **布局**：Flex，justify: space-between，align: center
- **左侧**：
  - 状态表情图标（32px，根据今日完成率变化）：
    - 0% → 😴 / 🌱
    - 1-30% → ☕ / 🐢
    - 31-60% → 🙂 / 🐇
    - 61-99% → 😊 / 🚀
    - 100% → 🎉 / ⭐

Kite 最具辨识度的设计元素，完整继承。

- **高度**：约 72px
- **布局**：横向 Flex，居中
- **内容**：
  - 左箭头：24px 圆形按钮，hover 浅灰背景，图标 ChevronLeft
  - 7 个日期项，等分宽度，每项间距 4px
  - 右箭头：同上
- **日期项设计**：
  - 默认态：圆角 `--radius-md` (8px)，padding 8px 12px，居中
    - 星期文字：12px，`--text-secondary`，如"周一"
    - 日期数字：14px，`--text-primary`，如"13"
  - **选中态（今日）**：
    - 背景：`--primary`
    - 星期 + 日期：白色
    - 底部小圆点（4px）：白色，表示有待办
  - **有待办但非今日**：底部小圆点（4px），`--primary` 色
  - **悬停态**：背景 `--bg-secondary`，150ms 过渡
- **切换逻辑**：点击左右箭头切换上一周/下一周；点击某天，下方列表切换到该日代办

## 6. 空状态与异常状态

### 6.1 空状态设计

所有空状态遵循统一模板：

- 大图标：48px，`--text-tertiary`，线性风格
- 主文案：18px, Medium, `--text-primary`
- 副文案：14px, `--text-secondary`
- 操作按钮：Primary 或 Ghost
- 垂直居中，padding 48px+

| 场景         | 图标 | 主文案             | 副文案                         | 操作         |
| ------------ | ---- | ------------------ | ------------------------------ | ------------ |
| 今日无代办   | 📝    | 今天还没有代办     | 添加一个代办，开始高效的一天   | + 添加代办   |
| 代办列表为空 | 📭    | 暂无代办           | 创建代办来管理你的任务         | + 新建代办   |
| 筛选结果为空 | 🔍    | 没有找到匹配的代办 | 尝试调整筛选条件               | 清除筛选     |
| 无日记       | 📓    | 还没有日记记录     | 每天记录一点点，见证成长轨迹   | 写第一篇日记 |
| 统计无数据   | 📊    | 还没有足够的数据   | 完成更多代办后，数据会自动汇总 | 去添加代办   |
| 归档列表为空 | ✅    | 还没有归档记录     | 完成任务并归档，积累成就感     | —            |

### 6.2 异常状态

| 场景         | 处理方式                                                     |
| ------------ | ------------------------------------------------------------ |
| 表单验证失败 | 错误字段边框变红（`--danger`），下方显示红色错误提示文字（13px） |
| 必填项未填   | 尝试提交时，未填字段抖动动画（shake，200ms）+ 聚焦           |
| 删除确认     | 二次确认弹窗："确定删除『xxx』？" + 取消 / 删除（Danger 按钮） |
| 操作成功     | InfoBar 顶部滑出：绿色左侧条 + 成功文案 + 自动消失 3s        |
| 操作失败     | InfoBar 顶部滑出：红色左侧条 + 错误文案 + 手动关闭           |

## 7. 动效与交互

### 7.1 页面切换

- 导航切换页面时：内容区 250ms 淡入（opacity 0→1）+ 轻微上移（translateY 4px→0）
- 使用 `QStackedWidget` 时，建议实现淡入淡出动画，避免生硬跳变

### 7.2 列表项动画

- 新增代办：卡片从上方滑入（translateY -16px→0, opacity 0→1），200ms
- 删除代办：卡片向左滑出 + 透明度降低，200ms，然后从 DOM/布局中移除
- 归档代办：卡片闪烁一次 `--success` 浅色背景（100ms），然后淡出消失（从待办列表移入已归档）

### 7.3 弹窗动画

- 创建/编辑弹窗：从下方滑入 20px + 透明度，200ms，`cubic-bezier(0.4,0,0.2,1)`
- 归档弹窗：缩放 0.95→1 + 透明度，250ms，略慢的仪式感
- 关闭：反向动画，150ms（更快，给人响应迅速的感觉）
- 遮罩：透明度 0→0.4/0.45，与弹窗同步

### 7.4 微交互

- 按钮悬停：背景色变化 + 150ms，Primary 按钮可增加轻微阴影 `--shadow-md`
- 卡片悬停：translateY(-1px) + `--shadow-md`，150ms
- Checkbox 勾选：内部勾选图标从 0.8→1.0 缩放 + 背景色填充，100ms
- 星星评分：hover 时星星放大 1.1 倍，点击时缩小回弹 0.9→1.0，弹性感
- 日期栏切换：选中日期的背景色变化有过渡，150ms

### 7.5 滚动行为

- 全局滚动条：自定义窄滚动条（6px 宽），轨道透明，滑块 `--bg-tertiary`，圆角 3px
- 弹窗内部滚动：同一样式，但滑块 hover 时变 `--text-tertiary`

### 9.2 技术建议

- **布局**：使用 Flexbox + Grid，不用框架（保持轻量，与 Qt 布局逻辑接近）
- **CSS 变量**：全部使用 CSS Custom Properties，便于主题切换演示

- **弹窗**：使用固定定位 + Flex 居中，遮罩层 `backdrop-filter: blur(2px)`（可选）

#### 9.3.1 Qt 样式表（QSS）背景级联规则（强制）

QSS 与前端 CSS 的关键差异：设置在控件上的样式表会**沿控件父子树向下级联**。在容器上写无选择器的 `background`（如 `container.setStyleSheet("background: #F3F4F6;")`），等价于对该容器子树内的 `* { background }`，会导致所有后代 QLabel / 图标控件被涂上一层祖先的背景色块，出现"文字/图标背景与所在卡片背景冲突"的现象。同理，类型选择器（如 `QFrame { ... }`）会匹配后代中所有该类型的子类（QLabel 继承自 QFrame），容器上同样禁止使用。

**规则**：

1. **容器**背景必须使用限定选择器，只作用于自身：
   - 自定义控件：用类选择器，如 `TaskCard { background: ... }`（类名不匹配后代，天然安全）；
   - 通用容器（QWidget/QFrame）：用 objectName 选择器，统一通过 `shiguang.ui.theme.set_container_bg(widget, name, color, radius)` 辅助函数设置；
   - 需要额外声明（如 border-left）时，手写 `#objectName { ... }`。
2. **叶子控件**（自身就是要显示底色的 Pill / Badge / 分割线 / 圆点，且无子控件）允许无选择器写法。
3. 文字/图标等展示控件不设置背景，保持透明，由所在容器统一提供背景色。

#### 9.3.2 控件图标规则（强制）

任何带图形的按钮或指示（^ v 步进箭头、下拉箭头、关闭 ×、加减号等）一律使用 Feather/Lucide 矢量 SVG（`resources/icons/` + `colored_icon` / `colored_pixmap` 着色），**禁止**：

1. Qt 原生风格绘制的子控件按钮（如 QSpinBox 上下箭头、QComboBox 原生 down-arrow）——点击区域小、渲染模糊、容易点击无响应；
2. 手画图标或用字符/Emoji 模拟按钮图标——精度缺失。

**标准替代控件**（`ui/widgets/form_fields.py`）：

| 场景 | 原生控件（禁止） | 替代实现 |
| ---- | ---------------- | -------- |
| 数字输入 | `QSpinBox`（^ v 箭头） | `NumberField`：文本输入 + 内嵌时钟图标 + 焦点下滚轮微调 |
| 下拉选择 | `QComboBox` 原生箭头 | `ChevronComboBox`：隐藏原生箭头 + chevron-down 矢量图标 |
